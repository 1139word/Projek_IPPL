Image Translator

Kebijakan Privasi

Berlaku sejak 24 November 2026.

Halaman ini menjelaskan data apa yang dikumpulkan ekstensi Chrome Image Translator beserta layanan pendukungnya, untuk apa data itu dipakai, dan dengan siapa data itu dibagikan.

1. Data dari akun Google

Saat Anda masuk dengan Google, aplikasi hanya meminta izin email dan profil dasar. Yang disimpan di basis data kami:

DataKegunaan
ID akun GoogleMengenali akun Anda setiap kali masuk.
Alamat emailDitampilkan di popup sebagai identitas akun Anda.
Alamat foto profilDitampilkan di popup ekstensi.

Kami tidak meminta akses ke Gmail, Google Drive, kontak, atau data Google lainnya.

2. Data penggunaan dan pembelian

  • Saldo credit akun Anda.
  • Sesi masuk: token sesi disimpan dalam bentuk hash beserta waktu kedaluwarsanya.
  • Riwayat pesanan credit: paket, harga, jumlah credit, status pembayaran, dan waktu pembayaran. Pembayaran QRIS diproses oleh Midtrans. Kami tidak menerima atau menyimpan data rekening, kartu, maupun dompet digital Anda.

3. Gambar yang diterjemahkan

Gambar yang Anda pilih untuk diterjemahkan dikirim ke server kami untuk dibaca dengan OCR. Gambar tidak disimpan: gambar hanya diproses di memori dan dibuang setelah hasil terjemahan dikirim ke ekstensi. Teks hasil OCR dikirim ke penyedia model terjemahan yang Anda pilih, yaitu Google Gemini atau DeepSeek, dan tunduk pada kebijakan privasi penyedia tersebut. Hasil terjemahan hanya ditampilkan di browser Anda dan tidak kami simpan.

4. Data yang disimpan di browser Anda

Ekstensi menyimpan pengaturan (bahasa asal, bahasa tujuan, model, tema, sakelar aktif) dan token sesi di penyimpanan lokal browser. Data ini tidak meninggalkan perangkat Anda, kecuali token sesi yang dikirim ke server kami untuk membuktikan bahwa Anda sudah masuk.

5. Berbagi data

Kami tidak menjual data Anda dan tidak memakainya untuk iklan. Data hanya dibagikan sejauh diperlukan agar fitur berjalan: Google (masuk akun), Midtrans (pembayaran), serta Google Gemini atau DeepSeek (terjemahan teks).

6. Menghapus data

Anda dapat keluar kapan saja melalui tombol Keluar di popup, yang menghapus sesi Anda. Untuk menghapus akun beserta seluruh datanya, hubungi kami melalui email di bawah. Data akan dihapus paling lambat 14 hari setelah permintaan diterima.
